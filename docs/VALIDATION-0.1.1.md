# TickNote 0.1.1 验证指南

先从托盘退出旧版，再启动新版；两个版本共用同一份正式数据。建议首先在「设置 → 数据管理 → 备份全部记录」保存一份 JSON 备份。安装包支持覆盖升级；便携版解压后运行 TickNote.exe。

## 建议验证顺序

1. **草稿**：浮窗输入内容，切换其他窗口后重新按热键，应保留草稿；关闭按钮会收起并保留，Esc 明确丢弃。主窗输入后退出再启动，应恢复草稿。
2. **AI**：设置中保存配置并测试连接。发起润色后继续编辑，旧结果不应覆盖新内容；润色期间记录并开始下一条，旧结果不应回填。连接测试只发送固定测试短句，润色只发送当前输入。
3. **列表与搜索**：加载更多后完成/删除任一条，不应退回第一页；搜索链接、路径、括号或引号中的原文应命中；搜索期间从浮窗新增匹配项，应自动出现。MCP 客户端写入后约 2 秒内刷新。
4. **详情**：编辑后失焦显示已保存，Ctrl+Enter 也可保存；复制有反馈。列表和详情删除均可在 5 秒内撤销。缩小到最小窗口，底部操作仍可直接点击。
5. **提醒**：设置 10 分钟后/1 小时后，或者自定义完整日期时间后点击「应用」。检查「提醒」筛选及状态；过了 18 点后按钮显示「明天 18:00」。系统通知依赖应用运行，Windows 勿扰可能静默通知。
6. **导出**：全量导出和筛选导出到同一目录，应得到不同子文件夹，前一次文件保持不变。
7. **备份**：备份生成 JSON。恢复时只合并缺失 ID，已有记录不会被旧备份覆盖；重复恢复应增加 0 条。备份不含 API Key，保留完整记录与提醒时间。不要为了测试在正式数据里清空记录。

## 界面细节回归

### 输入区焦点边框

1. 按全局热键唤起浮窗，自动聚焦后应只有外层绿色圆角边框，没有里面的深色直角框。
2. 通过 Tab 切换焦点，回到浮窗输入区仍无深色内框；待办/便签、关闭等按钮仍有键盘焦点提示。
3. 切换浅色、深色，检查浮窗、主窗输入、搜索和详情编辑区的边框。
4. 输入多行、Enter 记录、Shift+Enter 换行、失焦后恢复草稿，应与主流程一致。

已通过：打包程序自动聚焦、浅色/深色、Tab 切换后输入区无内框，按钮保留键盘焦点提示；搜索、主窗输入和详情正文的 outline 已检查。

### 外观菜单

1. 点击主窗右上角 `⋯`：菜单宽 240px，外观按钮为等宽横排胶囊，三个名称都应单行居中。
2. 依次切换跟随、浅色、深色，再打开菜单检查选中态。用 Tab / Shift+Tab 移动，焦点提示应可见，Enter / Space 可以切换主题。
3. 将窗口缩到最小 720×520，并在系统常用缩放下检查菜单不越界、按钮不换行。
4. 点击菜单外或按 Esc 应关闭菜单，「导出 Markdown」仍应打开范围选择弹窗。

已通过：三种主题 × 900×640 / 720×520 窗口 × 100% / 125% 页面缩放，共 12 种组合均无换行和菜单越界；Tab 焦点可见，Space 可切换并保存主题，Esc / 点击外部关闭菜单。Windows 系统 DPI 缩放仍请按实际环境手动确认。

### AI 润色按钮

1. 设置中启用 AI 润色，分别打开主窗和悬浮窗。空白草稿时按钮应禁用；输入文字后恢复可点击，保持普通边框和透明背景。
2. 鼠标移到按钮上时强调，移开恢复普通样式；Tab 聚焦时应有可见焦点，离开焦点后恢复。
3. 配置可用的 AI 服务后点击润色：运行中显示「润色中…」并禁用；结束后恢复可点击。点击「撤销润色」恢复原文，按钮保持普通样式（若鼠标仍悬停或键盘焦点仍在，允许显示对应交互提示）。
4. 分别在浅色和深色外观下检查，待办 / 便签的选中态仍保持绿色描边。

已通过：主窗 / 悬浮窗 × 浅色 / 深色均通过空白禁用、输入后普通样式、悬停、键盘焦点、运行中禁用与忙碌状态、撤销恢复原文检查。AI 请求使用本地模拟服务，不调用外部模型，不修改真实用户数据。

## 兼容性

- 数据库结构与 0.1.0 相同，无需转换；仍使用 `%APPDATA%\TickNote`。
- 原有 Markdown 文件保持原位置，新导出增加独立子文件夹。
- API Key 必须使用系统加密保存；若当前系统无法加密，会明确提示未保存。
- 本版仍为未签名的 Windows x64 应用。

## 已验证与待验证

- 已通过类型检查、lint、生产构建，Vitest 5 文件共 8 个用例，以及 Node/Electron 运行时的 MCP 端到端验证。
- 打包程序在隔离数据目录通过 9 项 UI 回归，另验证 JSON 备份合并、重复恢复、非法文件拒绝，以及实际 MCP 进程写入后搜索自动刷新。已检查浅色、深色和 720×520 布局。
- 安装/卸载、真实通知送达、自启与任务管理器禁用、中文输入法、多屏 DPI 仍需人工验证。
- 每日自动数据库备份、按 AI 批次撤销尚未实现。JSON 是记录备份，不含设置、API Key、未提交草稿及内部 ai_run_id。
